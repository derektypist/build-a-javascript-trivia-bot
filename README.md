# Build a JavaScript Trivia Bot

Practice working with JavaScript variables and strings by building a trivia bot.  How to use variables and basic strings.

## UX

[Build a JavaScript Trivia Bot User Stories](https://www.freecodecamp.org/learn/full-stack-developer/lab-javascript-trivia-bot/lab-javascript-trivia-bot)
## Technologies

Uses JavaScript.

## Deployment

Copy `script.js` to the text editor.  In `Node.js` command prompt, use the command `node script.js` to run the code.
